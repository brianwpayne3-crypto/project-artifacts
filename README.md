This repository is both the **source of truth and publishing source** for the public Project Artifacts site:

https://brianwpayne3-crypto.github.io/project-artifacts/

The site is intentionally iterative. Pages may evolve as the underlying product thinking, design work, or explanation of the work becomes clearer.

This repository is **not** a mirror of the underlying application repositories. Working code, operational data, customer information, internal issues, and implementation history generally remain in private project repositories.

## Publishing / synchronization rule

The public GitHub Pages site is generated directly from this repository's `main` branch. **Any change to a public artifact should be committed here as part of the same update.** There should not be a separate unpublished version of a page living only in chat, a private repo, or an ad-hoc local file.

When an artifact summarizes work from a private project repository, the private repository remains the source of truth for the actual project. This repository contains only the deliberately selected, sanitized public representation of that work.

## What belongs here

Good candidates:
- product and information-architecture diagrams;
- sanitized screenshots;
- design explorations;
- architecture diagrams intended for public discussion;
- project briefs and case-study material;
- selected prototypes or concepts;
- curated explanations of engineering and product leadership work.

Not appropriate:
- customer or personally identifiable information;
- secrets, credentials, private URLs, or production configuration;
- raw operational exports;
- private working notes that have not been deliberately selected for publication.

The rule is simple: **nothing becomes public here accidentally, and nothing published here should exist only outside Git.**
